Periskope UX Starter

This is your blank prototype workspace. The Periskope shell on the left and the page TopBar above are already wired up with real @netskope-ui/* components.

Build your first page with Claude

  1. In your terminal, run claude in this directory.
  2. Paste a Figma URL or a screenshot of the screen you want to build.
  3. Ask Claude to scaffold it at a new route, e.g. "Build this at app/incidents/dlp/page.tsx using @netskope-ui/* components inside <AppShell>."
  4. Refresh the browser at the new URL. Iterate with Claude until it looks right.
