# Design Patterns

Distilled from Confluence "[Fantastic Design Patterns (and where to find them)](https://netskope.atlassian.net/wiki/spaces/ENG/pages/4361650450/Fantastic+Design+Patterns+and+where+to+find+them)".

Each file is a short, AI-readable summary of a design decision the org has already made. Claude should consult these before composing the relevant UI — they encode "what we do at Netskope" so prototypes feel consistent with shipped product.
